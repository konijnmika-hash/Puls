# Foto's voor de workouts

Elke workout heeft nu een getekend omslagplaatje (kleur per categorie + bewegend sportfiguurtje).
Zet je hier een echte foto neer, dan gebruikt Puls die automatisch in plaats van de tekening:

- bestandsnaam = id van de workout, bijv. `rugdag.webp` (ook `.jpg` of `.png` werkt)
- liggend, ongeveer 5:4 (bijv. 1000 × 800 px), liefst `.webp` onder de 150 kB
- houd het onderwerp rechts: links onderin staat de tijd van de workout

Hieronder per workout een prompt die je kunt gebruiken in Google (Gemini / Imagen) of een andere beeldgenerator.
Eigen combinaties krijgen geen foto; die houden de tekening.
